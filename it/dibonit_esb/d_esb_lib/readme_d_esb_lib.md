📋 ESB Message Link Library - Final Specification

Here is the detailed specification for the new library. This document serves as the blueprint for implementation.
🎯 Overview

Purpose:
Provide a lightweight, secure, and efficient Unix Domain Socket (UDS)-based library for message exchange between two applications (APP_SRV and APP_CLI) on the same server.

Key Features:
    Connection Management:
        Server-side wait_connect (authenticates clients).
        Client-side connect (establishes connection).
    Heartbeat Mechanism:
        Server sends periodic heartbeats.
        Client responds with heartbeats Ack.
        Timeouts trigger 
			Error message to APP
			unlimited connection retrys at heatbeat rate. (client)
			disconnection and moving back to wait_connect (server).
    Message Exchange:
        get: Request data for a contract (returns DBuf).
        publish: Send data for a contract (returns OK/Error).
    Security:
        App name + password authentication.
        Token-based message validation (post-connection).
        UDS file permissions (0o600).
    Contract Validation:
        Server/client reject messages for unknown contracts.
    Error Handling:
        Sync errors: Returned via Result<T, EsbError>.
        Async errors (e.g., heartbeat failures): Propagated via callbacks.

}

Rationale:

    Tokens are generated by the server during wait_connect and sent to the client in the WELCOME DBuf.
    Every subsequent message (get, publish, heartbeat) must include the token in the DBuf header.
    The token_size field allows the receiver to parse the token correctly (even if it’s None).

Note:

    DBuf remains generic and contract-agnostic. All contract-specific logic (e.g., validation) is handled by msglink.rs, client.rs, and server.rs.
    No changes to DBuf methods (e.g., new, add_rows, get_row). Token handling is external.

#[derive(Debug, thiserror::Error)]
pub enum EsbError {
    /// Authentication failed (invalid app name or password).
    #[error("Connection refused: invalid app name or password")]
    ConnectionRefused,

    /// The requested contract is not in the allowed list.
    #[error("Contract '{0}' not found in the allowed list")]
    ContractNotFound(String),

    /// No heartbeat response received within the timeout.
    #[error("Heartbeat timeout: no response from peer")]
    HeartbeatTimeout,

    /// General communication error (e.g., socket closed unexpectedly).
    #[error("Communication error: {0}")]
    CommunicationError(String),

    /// Socket was closed by the peer.
    #[error("Socket closed unexpectedly")]
    SocketClosed,

    /// Token is missing, invalid, or expired.
    #[error("Invalid or expired token")]
    InvalidToken,

    /// I/O error (e.g., socket creation failed).
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
}

Usage:

    Synchronous errors (e.g., connect failure, invalid contract): Returned directly via Result<T, EsbError>.
    Asynchronous errors (e.g., heartbeat failure): Propagated via a callback (fn on_error(EsbError)).

/// Generates a cryptographically secure random token.
/// Size: up to `u32::MAX` bytes (practically limited by memory).
pub fn generate_token() -> Vec<u8> {
    use rand::RngCore;
    let mut token = vec![0u8; 32]; // Default to 32 bytes (256 bits)
    rand::thread_rng().fill_bytes(&mut token);
    token
}

/// Validates a token (constant-time comparison to prevent timing attacks).
pub fn validate_token(received: &[u8], expected: &[u8]) -> bool {
    use subtle::ConstantTimeEq;
    received.ct_eq(expected)
}

Note:

    Tokens are not stored in DBuf permanently. They are:
        Generated by the server during wait_connect.
        Sent to the client in the WELCOME DBuf (header fields: token, token_size).
        Included in the header of every subsequent DBuf (get, publish, heartbeat).

pub struct EsbServer {
    /// Configuration (socket path, heartbeat timeout, contracts).
    config: EsbConfig,

    /// Current session token (generated during `wait_connect`).
    token: Option<Vec<u8>>,

    /// List of allowed contracts (provided by APP_SRV).
    contracts: Vec<String>,

    /// Unix Domain Socket listener.
    listener: tokio::net::UnixListener,

    /// Channel to send heartbeat messages.
    heartbeat_tx: tokio::sync::mpsc::Sender<DBuf>,

    /// Callback for async errors (e.g., heartbeat timeout).
    error_callback: Option<Box<dyn Fn(EsbError) + Send + Sync>>,

    /// Channel to receive messages from the client.
    msg_rx: tokio::sync::mpsc::Receiver<DBuf>,

    /// Channel to send messages to the client.
    msg_tx: tokio::sync::mpsc::Sender<DBuf>,
}

impl EsbServer {
    /// Creates a new `EsbServer` instance.
    pub fn new(config: EsbConfig) -> Result<Self, EsbError> {
        let listener = create_socket(&config.socket_path)?;
        Ok(Self {
            config,
            token: None,
            contracts: config.contracts.clone(),
            listener,
            heartbeat_tx: tokio::sync::mpsc::channel(10).0,
            error_callback: None,
            msg_rx: tokio::sync::mpsc::channel(10).1,
            msg_tx: tokio::sync::mpsc::channel(10).0,
        })
    }

    /// Waits for a client connection and authenticates it.
    /// Returns `Ok(())` on success, or `EsbError` on failure.
    pub async fn wait_connect(&mut self, d_buf: &DBuf) -> Result<(), EsbError> {
        // 1. Extract app_name and password from `d_buf`:
        //    - `d_buf.name` should be "CONNECT".
        //    - Columns: "app_name" (char[20]), "password" (char[200]).
        //    - Additional columns: contracts (names only, values unused).
        let app_name = self.extract_app_name(d_buf)?;
        let password = self.extract_password(d_buf)?;
        let heartbeat_timeout = self.extract_heartbeat_timeout(d_buf)?;
        let contracts = self.extract_contracts(d_buf)?;

        // 2. Validate app_name/password (APP_SRV provides this logic via a callback or config).
        if !self.validate_credentials(&app_name, &password).await {
            return Err(EsbError::ConnectionRefused);
        }

        // 3. Generate a token and store it.
        let token = generate_token();
        self.token = Some(token.clone());
        self.contracts = contracts;

        // 4. Send a `WELCOME` DBuf to the client:
        //    - Name: "WELCOME"
        //    - Header: token, token_size, heartbeat_timeout, contracts (as columns).
        let welcome_dbuf = self.create_welcome_dbuf(&token, heartbeat_timeout, &contracts)?;
        self.send_dbuf(welcome_dbuf).await?;

        // 5. Start the heartbeat timer.
        self.start_heartbeat(heartbeat_timeout).await;

        // 6. Spawn a task to listen for incoming messages (get/publish).
        self.spawn_message_listener().await;

        Ok(())
    }

    /// Starts the heartbeat timer (sends `HEARTBEAT` DBuf periodically).
    async fn start_heartbeat(&self, timeout: std::time::Duration) {
        let token = self.token.clone().unwrap();
        let msg_tx = self.msg_tx.clone();
        let error_callback = self.error_callback.clone();
        let heartbeat_timeout = timeout;

        tokio::spawn(async move {
            let mut interval = tokio::time::interval(heartbeat_timeout);
            loop {
                interval.tick().await;
                let heartbeat_dbuf = create_heartbeat_dbuf(&token);
                if let Err(err) = msg_tx.send(heartbeat_dbuf).await {
                    if let Some(callback) = &error_callback {
                        callback(EsbError::CommunicationError("Failed to send heartbeat".into()));
                    }
                    break;
                }

                // Wait for Ack (with a short timeout, e.g., 500ms)
                let mut ack_rx = /* Channel to receive Ack */;
                if let Err(_) = tokio::time::timeout(
                    std::time::Duration::from_millis(500),
                    ack_rx.recv()
                ).await {
                    if let Some(callback) = &error_callback {
                        callback(EsbError::HeartbeatTimeout);
                    }
                    break;
                }
            }
        });
    }

    /// Listens for incoming messages (get/publish) and processes them.
    async fn spawn_message_listener(&self) {
        let msg_rx = self.msg_rx.clone();
        let token = self.token.clone().unwrap();
        let contracts = self.contracts.clone();
        let msg_tx = self.msg_tx.clone();
        let error_callback = self.error_callback.clone();

        tokio::spawn(async move {
            while let Some(d_buf) = msg_rx.recv().await {
                match d_buf.name.as_str() {
                    name if name.starts_with("GET_") => {
                        let contract = &name[4..]; // Strip "GET_"
                        if !contracts.contains(contract) {
                            if let Some(callback) = &error_callback {
                                callback(EsbError::ContractNotFound(contract.into()));
                            }
                            continue;
                        }
                        if !validate_token(&d_buf.token.unwrap_or_default(), &token) {
                            if let Some(callback) = &error_callback {
                                callback(EsbError::InvalidToken);
                            }
                            continue;
                        }
                        // Forward to APP_SRV for processing
                        let response = /* APP_SRV logic */;
                        msg_tx.send(response).await.unwrap();
                    }
                    name if name.starts_with("PUBLISH_") => {
                        let contract = &name[8..]; // Strip "PUBLISH_"
                        if !contracts.contains(contract) {
                            if let Some(callback) = &error_callback {
                                callback(EsbError::ContractNotFound(contract.into()));
                            }
                            continue;
                        }
                        if !validate_token(&d_buf.token.unwrap_or_default(), &token) {
                            if let Some(callback) = &error_callback {
                                callback(EsbError::InvalidToken);
                            }
                            continue;
                        }
                        // Forward to APP_SRV for processing
                        let response = /* APP_SRV logic */;
                        msg_tx.send(response).await.unwrap();
                    }
                    "HEARTBEAT" => {
                        // Handle heartbeat (should not happen server-side)
                    }
                    _ => {
                        if let Some(callback) = &error_callback {
                            callback(EsbError::CommunicationError(format!("Unknown message: {}", d_buf.name)));
                        }
                    }
                }
            }
        });
    }

pub struct EsbClient {

    config: EsbConfig,

    token: Option<Vec<u8>>,

    /// List of allowed contracts (received from server).
    contracts: Vec<String>,

    /// Unix Domain Socket stream.
    stream: tokio::net::UnixStream,

    /// Heartbeat timeout (for reconnection).
    heartbeat_timeout: std::time::Duration,

    /// Callback for async errors (e.g., heartbeat failure).
    error_callback: Option<Box<dyn Fn(EsbError) + Send + Sync>>,

    /// Channel to send messages to the server.
    msg_tx: tokio::sync::mpsc::Sender<DBuf>,

    /// Channel to receive messages from the server.
    msg_rx: tokio::sync::mpsc::Receiver<DBuf>,
}

impl EsbClient {
    /// Connects to the server.
    /// Returns `EsbClient` on success, or `EsbError` on failure.
    pub async fn connect(config: EsbConfig, d_buf: &DBuf) -> Result<Self, EsbError> {
        // 1. Extract app_name and password from `d_buf`:
        //    - `d_buf.name` should be "CONNECT".
        //    - Columns: "app_name" (char[20]), "password" (char[200]).
        let app_name = extract_app_name(d_buf)?;
        let password = extract_password(d_buf)?;

        // 2. Connect to the server socket.
        let stream = tokio::net::UnixStream::connect(&config.socket_path).await?;

        // 3. Send the `CONNECT` DBuf.
        let connect_dbuf = create_connect_dbuf(&app_name, &password)?;
        let bytes = serialize_dbuf(&connect_dbuf)?;
        stream.writable().await?;
        stream.write_all(&bytes).await?;

        // 4. Wait for `WELCOME` DBuf:
        let welcome_bytes = read_dbuf(&stream).await?;
        let welcome_dbuf = deserialize_dbuf(&welcome_bytes)?;

        // 5. Extract token, contracts, and heartbeat_timeout from `WELCOME` DBuf.
        let token = welcome_dbuf.d_buf_header.token;
        let token_size = welcome_dbuf.d_buf_header.token_size;
        let heartbeat_timeout = extract_heartbeat_timeout(&welcome_dbuf)?;
        let contracts = extract_contracts(&welcome_dbuf)?;

        // 6. If heartbeat_timeout is 0, default to 60 seconds.
        let heartbeat_timeout = if heartbeat_timeout.is_zero() {
            std::time::Duration::from_secs(60)
        } else {
            heartbeat_timeout
        };

        // 7. Spawn a task to listen for heartbeats and respond with Ack.
        let (msg_tx, msg_rx) = tokio::sync::mpsc::channel(10);
        let client = Self {
            config,
            token: token.clone(),
            contracts,
            stream,
            heartbeat_timeout,
            error_callback: None,
            msg_tx: msg_tx.clone(),
            msg_rx,
        };
        client.spawn_heartbeat_listener(msg_tx, token, heartbeat_timeout).await;

        Ok(client)
    }

    /// Spawns a task to listen for heartbeats and respond with Ack.
    async fn spawn_heartbeat_listener(
        &self,
        msg_tx: tokio::sync::mpsc::Sender<DBuf>,
        token: Option<Vec<u8>>,
        heartbeat_timeout: std::time::Duration,
    ) {
        let stream = self.stream.try_clone().unwrap();
        let error_callback = self.error_callback.clone();

        tokio::spawn(async move {
            let mut stream = stream;
            let mut buf = vec![0u8; 1024];
            loop {
                // Read a DBuf from the stream
                let n = match stream.read(&mut buf).await {
                    Ok(n) if n == 0 => break, // Connection closed
                    Ok(n) => n,
                    Err(_) => break,
                };
                let d_buf = match deserialize_dbuf(&buf[..n]) {
                    Ok(d_buf) => d_buf,
                    Err(_) => break,
                };

                // Check if it's a heartbeat
                if d_buf.d_buf_header.name == b"HEARTBEAT" {
                    // Validate token
                    if let Some(ref token) = token {
                        if !validate_token(&d_buf.d_buf_header.token.unwrap_or_default(), token) {
                            if let Some(callback) = &error_callback {
                                callback(EsbError::InvalidToken);
                            }
                            break;
                        }
                    }

                    // Send Ack
                    let ack_dbuf = create_ack_dbuf(&d_buf);
                    let ack_bytes = serialize_dbuf(&ack_dbuf).unwrap();
                    if let Err(_) = stream.write_all(&ack_bytes).await {
                        break;
                    }
                }
            }

            // If we exit the loop, the connection is lost
            if let Some(callback) = error_callback {
                callback(EsbError::HeartbeatTimeout);
            }
            // Attempt to reconnect (not implemented here; APP_CLI should handle this)
        });
    }

    /// Sends a `get` request for a contract.
    /// Returns the response `DBuf` on success, or `EsbError` on failure.
    pub async fn get(&mut self, contract: &str, input_dbuf: &DBuf) -> Result<DBuf, EsbError> {
        // 1. Validate that `contract` is in `self.contracts`.
        if !self.contracts.contains(contract) {
            return Err(EsbError::ContractNotFound(contract.into()));
        }

        // 2. Create a `GET_{contract}` DBuf:
        //    - Name: "GET_{contract}"
        //    - Header: token, token_size
        //    - Row values: input_dbuf.d_buf_row_values
        let get_dbuf = create_get_dbuf(contract, &self.token, input_dbuf)?;

        // 3. Send the DBuf.
        self.send_dbuf(get_dbuf).await?;

        // 4. Wait for response.
        let response = self.receive_dbuf().await?;

        // 5. Return the response.
        Ok(response)
    }

    /// Sends a `publish` request for a contract.
    /// Returns `Ok(())` on success, or `EsbError` on failure.
    pub async fn publish(&mut self, contract: &str, input_dbuf: &DBuf) -> Result<(), EsbError> {
        // 1. Validate that `contract` is in `self.contracts`.
        if !self.contracts.contains(contract) {
            return Err(EsbError::ContractNotFound(contract.into()));
        }

        // 2. Create a `PUBLISH_{contract}` DBuf:
        //    - Name: "PUBLISH_{contract}"
        //    - Header: token, token_size
        //    - Row values: input_dbuf.d_buf_row_values
        let publish_dbuf = create_publish_dbuf(contract, &self.token, input_dbuf)?;

        // 3. Send the DBuf.
        self.send_dbuf(publish_dbuf).await?;

        // 4. Wait for "OK" or error response.
        let response = self.receive_dbuf().await?;
        if response.d_buf_header.name == b"OK" {
            Ok(())
        } else {
            Err(EsbError::CommunicationError("Publish failed".into()))
        }
    }

    /// Sets the error callback (for async errors like heartbeat failures).
    pub fn set_error_callback(&mut self, callback: impl Fn(EsbError) + Send + Sync + 'static) {
        self.error_callback = Some(Box::new(callback));
    }

    /// Helper: Sends a DBuf to the server.
    async fn send_dbuf(&self, d_buf: DBuf) -> Result<(), EsbError> {
        let bytes = serialize_dbuf(&d_buf)?;
        self.stream.writable().await?;
        self.stream.write_all(&bytes).await?;
        Ok(())
    }

    /// Helper: Receives a DBuf from the server.
    async fn receive_dbuf(&self) -> Result<DBuf, EsbError> {
        let mut buf = vec![0u8; 1024];
        let n = self.stream.read(&mut buf).await?;
        deserialize_dbuf(&buf[..n])
    }
}

            name: b"ACK_HEARTBEAT".to_vec(),
            token: heartbeat_dbuf.d_buf_header.token.clone(),
            token_size: heartbeat_dbuf.d_buf_header.token_size,
            ..Default::default()
        },
        d_buf_row_values: Vec::new(),
    }
}

🔄 Message Flow Examples
1. Connection (wait_connect / connect)
Server Side (wait_connect)

    APP_SRV creates an EsbServer with:
        socket_path: /tmp/app_srv.sock
        heartbeat_timeout: Duration::from_secs(5)
        contracts: ["contract1", "contract2"]
    APP_SRV calls server.wait_connect(&d_buf), where d_buf is a CONNECT DBuf with:
        name: "CONNECT"
        Columns:
            app_name: "APP_CLI" (char[20])
            password: "s3cret" (char[200])
            heartbeat_timeout: 5 (u32)
            contract1: (char[50], value unused)
            contract2: (char[50], value unused)
    Server validates app_name/password:
        If invalid: Returns EsbError::ConnectionRefused (logs error).
        If valid:
            Generates a token (e.g., [1, 2, 3, ..., 32]).
            Sends a WELCOME DBuf with:
                name: "WELCOME"
                Header:
                    token: [1, 2, 3, ..., 32]
                    token_size: 32
                    heartbeat_timeout: 5 (u32)
                    Columns: contract1, contract2 (names only)
    Server starts the heartbeat timer (sends HEARTBEAT DBuf every 5 seconds).
    Server spawns a task to listen for incoming messages (get/publish).

Client Side (connect)

    APP_CLI creates an EsbConfig with:
        socket_path: /tmp/app_srv.sock
        heartbeat_timeout: Duration::from_secs(0) (will default to 60s)
    APP_CLI calls EsbClient::connect(config, &d_buf), where d_buf is a CONNECT DBuf with:
        name: "CONNECT"
        Columns:
            app_name: "APP_CLI" (char[20])
            password: "s3cret" (char[200])
    Client connects to /tmp/app_srv.sock and sends the CONNECT DBuf.
    Client waits for WELCOME DBuf:
        Extracts:
            token: [1, 2, 3, ..., 32]
            token_size: 32
            heartbeat_timeout: 5 (defaults to 60s if 0)
            contracts: ["contract1", "contract2"]
    Client spawns a task to listen for HEARTBEAT messages and respond with Ack.
    Client returns the EsbClient instance.

2. Heartbeat
Server → Client

    Every 5 seconds, the server sends a HEARTBEAT DBuf:
        name: "HEARTBEAT"
        Header:
            token: [1, 2, 3, ..., 32]
            token_size: 32
    If no Ack is received within 500ms:
        Server closes the socket.
        Server calls error_callback(EsbError::HeartbeatTimeout).
        Server returns to wait_connect to wait for a new connection.

Client → Server

    On receiving a HEARTBEAT DBuf:
        Client validates the token (matches the one received in WELCOME).
        Client sends an ACK_HEARTBEAT DBuf:
            name: "ACK_HEARTBEAT"
            Header:
                token: [1, 2, 3, ..., 32]
                token_size: 32
    If no HEARTBEAT is received within 10 seconds (5 * 2):
        Client calls error_callback(EsbError::HeartbeatTimeout).
        Client attempts to reconnect (same heartbeat_timeout).

3. get Request
Client Side

    APP_CLI calls client.get("contract1", &input_dbuf).
    Client validates that "contract1" is in self.contracts:
        If not: Returns EsbError::ContractNotFound.
    Client creates a GET_contract1 DBuf:
        name: "GET_contract1"
        Header:
            token: [1, 2, 3, ..., 32]
            token_size: 32
        Row values: input_dbuf.d_buf_row_values
    Client sends the DBuf and waits for response.
    Server processes the request and sends a response DBuf (e.g., with data for contract1).
    Client returns the response DBuf.

Server Side

    Server receives the GET_contract1 DBuf.
    Server validates the token:
        If invalid: Returns EsbError::InvalidToken.
    Server validates the contract ("contract1" is in self.contracts):
        If not: Returns EsbError::ContractNotFound.
    Server processes the request (via APP_SRV logic) and sends a response DBuf.

4. publish Request
Client Side

    APP_CLI calls client.publish("contract1", &input_dbuf).
    Client validates the contract (same as get).
    Client creates a PUBLISH_contract1 DBuf:
        name: "PUBLISH_contract1"
        Header:
            token: [1, 2, 3, ..., 32]
            token_size: 32
        Row values: input_dbuf.d_buf_row_values
    Client sends the DBuf and waits for "OK" or error.

Server Side

    Server validates token and contract (same as get).
    Server processes the publish request (via APP_SRV logic).
    Server sends an "OK" DBuf or error.

📌 Key Design Decisions Summary
Decision	Rationale
Token in DBuf header	Ensures all messages are authenticated without extra wrapping.
No serde	DBuf is already binary; no need for serialization overhead.
Heartbeat timeout	Configurable by APP_SRV; client uses timeout * 2 for reconnection.
UDS permissions	0o600 restricts access to the socket file.
Error callbacks	Async errors (e.g., heartbeat failures) are propagated via callbacks.
Contract validation	Server/client check against self.contracts before processing messages.
No multi-client in lib	APP_SRV manages multiple connections by spawning multiple EsbServer instances (one per socket/thread).
✅ Validation Checklist

    Token in DBuf header: Added token and token_size fields to DBufHeader.
    UDS permissions: Socket created with 0o600.
    Heartbeat:
        Server sends HEARTBEAT every heartbeat_timeout.
        Client responds with Ack.
        Timeouts: Server (500ms), Client (heartbeat_timeout * 2).
    Error handling:
        Sync errors: Returned via Result<T, EsbError>.
        Async errors: Propagated via callbacks.
    Contract validation: Server/client check against self.contracts.
    No serde: Uses raw DBuf serialization.
    Minimal dependencies: Only tokio, thiserror, log.
